# Validación del mockup — Sol Mai Peluquería

## Proyecto

**Sol Mai Peluquería** es el proyecto de presencia digital y reserva de turnos para el negocio, con foco inicial en validar una experiencia visual y funcional de mockup antes de avanzar hacia un MVP operativo.

Este documento cierra documentalmente la **Fase 0** del proyecto: validación del mockup aprobado como baseline de producto.

## Fecha de validación

La validación documental de esta fase queda registrada con fecha **30 de mayo de 2026**.

## Validación por la dueña del negocio

El mockup fue validado por la dueña de Sol Mai Peluquería como referencia aprobada para continuar el desarrollo del MVP funcional. La aprobación corresponde al aspecto visual, narrativa, estructura de navegación y flujo conceptual de reserva presentado en el mockup.

## Alcance aprobado

El alcance aprobado cubre la experiencia de mockup para:

- Presentación del negocio en landing page.
- Identidad visual inicial con logo real.
- Copy comercial y descriptivo.
- Cards visuales de servicios o propuestas.
- Flujo conceptual de reserva de turno.
- Navegación y comportamiento responsive desktop/mobile.
- Pantallas y estados necesarios para explicar la experiencia esperada del usuario.

## Qué incluye el mockup

El mockup validado incluye:

- Landing desktop.
- Landing mobile.
- Header mobile.
- Navegación principal.
- Logo real del negocio.
- Copy base aprobado para la presentación comercial.
- Cards visuales para comunicar servicios o beneficios.
- Wizard o flujo visual de reserva.
- Selección de categoría.
- Selección de servicio.
- Personalización del turno o servicio.
- Extras disponibles dentro del flujo.
- Resumen mobile de la reserva.
- Publicación del mockup como referencia validada.

## Qué no incluye todavía

El mockup validado **no** representa aún el MVP funcional final. Todavía no incluye, salvo que se desarrolle en fases posteriores:

- Persistencia real de reservas.
- Backend productivo.
- Integración con calendario o agenda real.
- Gestión administrativa de turnos.
- Confirmaciones automáticas por WhatsApp, email u otro canal.
- Sistema de autenticación.
- Panel interno para la dueña del negocio.
- Catálogo editable desde una interfaz administrativa.
- Pagos, señas o integraciones comerciales.
- Reglas definitivas de disponibilidad, duración, precios o recursos.
- Métricas productivas o analítica final.

## Baseline técnica congelada

La baseline aprobada del mockup queda asociada a:

- Rama congelada: `mockup-validado-v1`.
- Release/tag: `v0.1-mockup-validado`.

La rama `mockup-validado-v1` debe conservarse como referencia histórica y no debe recibir cambios posteriores. Cualquier evolución del producto debe compararse contra esta baseline para preservar trazabilidad entre lo validado y lo implementado.

## Próximos pasos hacia el MVP funcional

Los próximos pasos recomendados son:

1. Definir alcance funcional mínimo del MVP sobre la baseline aprobada.
2. Priorizar funcionalidades críticas para reserva real de turnos.
3. Diseñar modelo de datos inicial para servicios, categorías, extras y reservas.
4. Definir estrategia de persistencia y despliegue.
5. Implementar el flujo funcional manteniendo consistencia con el mockup validado.
6. Agregar validaciones, estados de error y confirmaciones del usuario.
7. Preparar pruebas de aceptación con la dueña del negocio.
8. Documentar diferencias entre mockup validado y MVP implementado.
